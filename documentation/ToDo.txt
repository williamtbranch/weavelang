### Primary Objectives & Guiding Principles

- **Goal:** Overhaul the data pipeline to be language-agnostic, self-validating,
  and produce a lean, intention-revealing JSON schema (v2.5) for the Rust consumer.
- **Architecture:** A two-phase pipeline. Phase 1 is LLM-heavy for creative text
  generation. Phase 2 is SpaCy-heavy for deterministic linguistic annotation.
- **The Golden Rule of Lemmatization:** To derive a word's lemma, its original
  full-sentence context MUST be provided to SpaCy.

### The New 6-Stage Pipeline Flow

(Abridged - Full description in current_context.txt)
- **Stage 1: `InitializeBookTiers` (LLM):** Creates base/advanced `full_text`.
- **Stage 2: `SegmentCoreTiers` (SpaCy):** Segments core tiers.
- **Stage 3: `GenerateDerivedTiers` (LLM):** Creates derived tier text.
- **Stage 4: `GenerateMappings` (LLM):** Creates raw diglot maps.
- **Stage 5: `TokenizeAndLemmatizeSimplerTarget` (SpaCy):** Annotates `simpler_advanced_target`.
- **Stage 6: `FinalizeAnnotations` (SpaCy):** Annotates all remaining tiers,
  standardizes boundaries, lemmatizes mappings, and cleans up temporary data.
