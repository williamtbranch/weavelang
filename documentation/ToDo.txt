### Primary Objectives & Guiding Principles

- **Goal:** Implement a smoother, more pedagogically sound learning gradient by refactoring the pipeline and engine to support a three-tier simplification model (Simple, Basic, Moderate).
- **Architecture:** The Python pipeline will produce these three distinct tiers of simplified text. The Rust engine will intelligently weave them together, prioritizing more natural prose as the learner's vocabulary grows.
- **Golden Rule:** The "jarring" stylistic gap must be eliminated. The learner's journey should be a gradual ascent from functional, deconstructed language to fluent, natural prose, before reaching the final, literary text.

#### Phase 3: Rust Engine Refactor

- [ ] **Task 3.1: Update JSON Parsing and Numerical Types**
    - [ ] In `json_types.rs`, add `moderate_target` and `basic_target` to the data structures.
    - [ ] In `numerical_types.rs`, update the `NumericalAdvSegmentBundle` struct to hold the text and lemma IDs for the `Moderate` and `Basic` tiers.
    - [ ] Update `preprocessor.rs` to correctly map the new JSON tiers to the updated numerical structs.

- [ ] **Task 3.2: Implement the New L0 Weaving Logic**
    - [ ] In `core_algo.rs`, modify the `try_build_advanced_weave` function.
    - [ ] Implement the new four-step fallback logic for each segment:
        1. Attempt to use `Advanced` text.
        2. If fails, attempt to use `Moderate` text.
        3. If fails, attempt to use `Basic` text.
        4. If fails, attempt to use `Simple` text.
        5. If all fail, fall back to the Inverse Diglot mechanism using the `Simple` text as the base.
